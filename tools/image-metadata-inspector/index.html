Image Metadata Inspector

See everything your photos reveal: camera model, capture time, GPS coordinates, XMP, IPTC and ICC profiles — then strip it and download a clean copy. Parsed entirely in your browser; the file never leaves your device.

Drop an image here, or browse

JPEG, PNG, WebP and GIF. Read locally — nothing is uploaded, nothing is stored.

Metadata is read from the container's own segments and tags — the pixel data is never decoded, so this is safe on untrusted files. Only JPEG, PNG, WebP and GIF are recognised.
