OpenAPI Request Builder

Load an OpenAPI 3 or Swagger 2 document, pick an operation, fill in the parameters, and get a ready-to-run request with curl, fetch, Node, Python and raw HTTP snippets. The spec never leaves your tab.

1 · SPEC
Drop an .json OpenAPI or Swagger file here, or click to choose

Parsed entirely in memory — the document is never uploaded or saved. YAML specs should be converted to JSON first.
