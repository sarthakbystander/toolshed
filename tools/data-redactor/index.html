How this works

Every byte you paste is processed in this tab. The tool runs a set of pattern detectors over your text, keeps the ones whose checksums validate (card numbers must pass Luhn, IBANs must pass the mod-97 check), and replaces each match with the strategy you choose. The results table lists exactly what it changed so you can audit it before sharing the output.

Redact and remove are irreversible. Mask keeps a couple of characters for readability. Hash gives a stable, salted fingerprint you can join on without ever revealing the original. Tokenize assigns a numbered label per distinct value.

Detectors are pattern-based, so they can miss unusual formats and can occasionally flag something harmless. Always review the findings list before sharing the output — treat it as a careful first pass, not a guarantee.
