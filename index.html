    How it works

    Four rules we hold to
    01

    Browser-first

    Tools run locally whenever possible. No backend, no accounts, no data collection.

    02

    One job each

    Every directory under tools/ is a self-contained page that does one thing.

    03

    Easy to add

    Contributing means adding a folder. It never requires touching the shell around it.

    04

    Minimal deps

    Browser APIs, vanilla JavaScript, plain HTML and CSS. Anything else has to earn it.

    Add your own tool.

    No framework, no build step. Drop a folder into tools/and open a pull request. It appears here once merged.
